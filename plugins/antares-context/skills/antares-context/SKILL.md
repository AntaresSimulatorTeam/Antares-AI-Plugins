# Antares ecosystem context

This skill only orients the user. It does not operate any tool. Load the reference that matches the question:

- `references/ecosystem.md`: what each product does and how they fit together. Use it for "what is X" or
  "which tool should I use to …" questions.
- `references/repos.md`: public repositories of the AntaresSimulatorTeam GitHub organisation and what each
  holds. Use it for "where is the code / docs for X" questions.
- `references/interactions.md`: study formats, tool interactions and integration checks. Use it for questions
  about dependencies between products or the scope of an impact analysis.
- `references/product-vision.md`: publicly documented purposes and GEMS ambitions, plus explicitly labelled
  working hypotheses. Use it for questions about direction or user value, not as proof of a team decision.

The references draw on public information as of 2026-11; their hypotheses are not approved objectives or
roadmap commitments. If a question needs current details (versions, options, install steps or decisions), point
the user to the product's documentation or repository instead of guessing.
