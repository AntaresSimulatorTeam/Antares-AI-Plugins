# AntaresSimulatorTeam public repositories

Public repositories of https://github.com/AntaresSimulatorTeam, with their GitHub description or README summary,
as of 2026-11-17. Archived repositories and forks are omitted.

## Simulator

| Repository | Holds |
|------------|-------|
| Antares_Simulator | Simulator source (C++): `antares-solver`, `antares-modeler`, helper tools, and reference docs under `docs/` |
| antares-doc | User documentation website (MkDocs), published at antares-doc.readthedocs.io |
| SimTest | Reference studies and results for Antares_Simulator |
| Antares_Simulator_Tests_NR, simulator-cucumber-tests, Antares_Simulator_Examples, antares-vcpkg-registry | No public description |

## Antares Web

| Repository | Holds |
|------------|-------|
| AntaREST | Antares Web: REST API and web application for Antares Simulator studies |
| antares_desktop | AntaresWeb Desktop instances |
| antares-web-installer | Antares Web Desktop installer |
| antarest-python-client | Python client for the AntaREST API |

## Modelling and investment

| Repository | Holds |
|------------|-------|
| antares-xpansion | Antares Xpansion: investment simulations based on Antares Simulator studies |
| GEMS | Generic Energy systems Modelling Schema: language, docs, examples |
| GemsPy | Python interpreter for GEMS |
| GEMS-ViewsBuilder | Python prototype for a GEMS Business View Builder |
