## `study.antares`

```ini
[antares]
version = 10.3
caption = <study name>
created = <Unix timestamp>
lastsave = <Unix timestamp>
author = <name>
editor = <name>
```

- Keys are read case-insensitively. The writer emits `lastSave` (`header.cpp:59-72`, `inifile` lowercases keys).
- `editor` is written on save but not read back (`header.cpp:114`).
- Defaults when missing: author `Unknown`, caption `No title` (`include/antares/study/header.h:15-18`).
- A missing `[antares]` section logs "The main section has not been found. The study seems invalid."
  (`header.cpp:154`).

### Supported versions

`src/libs/antares/study/version.cpp:13-22`: 7.0, 7.1, 7.2, 8.0–8.8, 9.0–9.3, 10.0–10.3. Legacy studies store the
version as an integer (`880` → 8.8, `version.cpp:30-46`). A version above the solver's maximum logs "Maximum study
version supported: …" (`version.cpp:158-162`).

## `settings/generaldata.ini`

Sections recognised by the loader (`src/libs/antares/study/parameters.cpp:1223-1233`):

`[general]`, `[input]`, `[output]`, `[optimization]`, `[adequacy patch]`, `[other preferences]`,
`[advanced parameters]`, `[playlist]`, `[variables selection]`, `[seeds - Mersenne Twister]`, `[compatibility]`.

Section names are matched lowercase. Some keys used by these skills:

| Section | Key | Meaning | Source |
|---------|-----|---------|--------|
| `[general]` | `mode` | `economy`/`economic`, `adequacy`, `expansion` (case-insensitive). Default `economy` | `docs/reference/solver/parameters.md:16-35` |
| `[general]` | `nbyears` | Number of Monte-Carlo years | `parameters.md:52` |
| `[general]` | `generate` | Time-series kinds generated by the stochastic generators | `parameters.cpp:408-410` |
| `[general]` | `custom-scenario` | Use `settings/scenariobuilder.dat` | `inputs.md:84` |
| `[input]` | `import` | Time-series kinds written back into `input/` after a run | `parameters.cpp:512-514` |

The solver logs "Unknown section name" as an **error** for any other section (`parameters.cpp:1236-1248`). Errors
stop a run unless `--force` is given.

The full parameter reference is `docs/reference/solver/parameters.md` in Antares_Simulator. It is marked "under
construction" and has open TODOs, so treat it as incomplete.

### Area name → folder id

Folders use the area **id**, not its name (`src/libs/antares/utils/include/antares/utils/utils.hxx:14-41`):

- Keep `a-z A-Z 0-9 _ - ( ) , &` and space.
- Replace each run of other characters with a single space.
- Trim, then lowercase.

Example: `FR Paris/Nord` → `fr paris nord`.

Other themes (renewables, short-term storage, links, reserves, misc. gen.) are documented in
`docs/reference/solver/inputs.md`.

## File-format rules

From `docs/developer-guide/8-study-format-conventions.md`:

- File names must use Latin characters only.
- Numbers use a decimal point (`4.4`, not `4,4`). Negative numbers start with `-`. Scientific notation is allowed.
- Time series are TAB-separated text files, one row per line, all columns with the same number of rows. Hourly
  series usually have 8760 rows.
- An empty time-series file means one column of zeros.
- Parameters are INI or YAML. Keys must be unique within an INI section.

## `output/`

Each run creates `output/<YYYYMMDD-HHMM><eco|adq|exp>` plus `-<name>` when a simulation name is given
(`src/libs/antares/study/study.cpp:185-197`). The output contains `about-the-study/` with copies of the header,
comments and parameters (`study.cpp:250-311`), and `mc-all/` results. See `docs/reference/solver/outputs.md`.
